# PMP Learning Portfolio

This repository documents my hands-on learning as I work toward the
Project Management Professional (PMP) certification through the
Onward to Opportunity (O2O) / HomeFront Orange program.

My goal is to go beyond studying project management concepts and
actually apply them through project artifacts, templates, reflections,
and a simulated technical project.

---

## Capstone Case Study

### Secure IAM Modernization Project

For this portfolio, I am using a simulated enterprise project focused
on modernizing an Identity and Access Management environment.

The project will allow me to apply project management concepts to a
technical environment that includes:

- Identity and Access Management
- Authentication and authorization
- Application onboarding
- Cloud environments
- Cybersecurity requirements
- Stakeholder coordination
- Risk management
- Technical dependencies
- Compliance requirements
